# 路线图

本页说明方向，不承诺固定时间或尚未验证的兼容能力。

## 当前：默认 NSIS 与可选 Rust 引擎

已具备配置初始化、检查和构包，品牌化原生 UI，当前用户安装、完整包升级、受控卸载、静默入口及诊断。原有 NSIS 后端保持默认；新增 `build --engine rust` 使用 x64 Rust worker，无需 NSIS/bridge，复用配置、界面和安装记录。

NSIS 正常样例链已有本机验证。2026-10-12 的 Rust Release 候选通过本机 19 项安装生命周期、6 项进程中断验收及 281 项源码测试。2026-10-13 完成同一候选在当前缩放下的一次 GUI 安装、启动和卸载；卸载画面与关闭由人工确认，后台结果独立核验。范围和复现入口见[开发指南](development.md#rust-引擎真实进程验收)。真实产品、更多环境和公开二进制发布分别验证。

支持边界见[兼容约定](compatibility.md)。源码公开不表示全部发布验收已完成。

## Rust 引擎本阶段验收

本次真实进程报告覆盖以下生命周期；结果对应本次组件与输入，不继承旧 NSIS 包的通过结论：

1. 未压缩载荷读取、部署、系统入口、取消和归属卸载。
2. 完整包升级、暂存/备份、完整提交、有限进程内回滚与用户内容保护。
3. 部分写入、提交前后失败、恢复失败、异常退出和只读诊断。
4. 满足现有完整性约定的 NSIS 安装识别、资源迁移、卸载器交接及迁移失败恢复。

迁移验收使用本次 runtime、CLI 与既有 NSIS header/bridge 生成的真实 NSIS A 包，验证正常迁移和提交前失败恢复；不代表所有历史 runtime 已认证。异常退出覆盖三个事务暂停点，不代表任意指令中断或机器重启恢复。

Rust 通过显式参数选用，默认切换另行决定。当前原生载荷不压缩，保留现有包大小限制；压缩与性能优化单独评估，不预先承诺性能收益。50 000 文件边界、性能、签名和独立环境测试本次未做，后续安排不因引擎加入自动改变。
