# 路线图

本页说明方向，不承诺固定时间或尚未验证的兼容能力。

## 当前：NSIS 开发者预览

已具备配置初始化、检查和构包，品牌化原生 UI，当前用户安装、完整包升级、受控卸载、静默入口及诊断。正常样例链已有本机验证；真实产品、更多环境和公开二进制发布分别验证。

支持边界见[兼容约定](compatibility.md)。源码公开不表示全部发布验收已完成。

## 近期方向：Rust 原生执行引擎

复用已有配置、展示和安装记录语义，逐步实现：

1. 载荷读取、部署、系统入口、取消和卸载。
2. 完整包升级、暂存/备份、提交与有限恢复。
3. 与生命周期对应的失败和中断验证。
4. 历史 NSIS 安装识别、记录/资源迁移和卸载器交接。

候选通过正常及失败路径后再提供可选后端；默认切换还需验证历史安装接管与迁移失败处理。性能变化以同条件测量为准，不预先承诺收益。

## 后续能力

- 全用户安装与明确提权边界。
- 组件选择和更多品牌布局。
- 可信更新元数据、完整包下载验证及已有升级流程的组合。
- Rust 页面与组件扩展。

服务、驱动、重启续装、差分包、应用数据库迁移分别设计。签名、目标环境和发布验证按实际交付范围安排。
